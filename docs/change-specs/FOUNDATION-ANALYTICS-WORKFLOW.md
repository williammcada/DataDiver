# DataDiver — Foundation Analytics Workflow

**Status:** Product direction; no source implementation is asserted.

## Intended capability

DataDiver supports an **Overview**, **Item Explorer**, **Teacher Reports**, **School Report**, **Method**, and **Data Dive Report** workflow. It distinguishes Priority, Monitor, Aligned, and Strength signals and must make calculations, denominators, thresholds, and limitations inspectable.

## Acceptance checks

| Check | Result |
| --- | --- |
| Reported classifications have documented calculation rules | Not run |
| Item-level results and aggregate reports reconcile | Not run |
| Any external data import is validated and preserves its provenance | Not run |
